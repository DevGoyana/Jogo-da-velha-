# Jogo da Velha

Projeto de um **Jogo da Velha** desenvolvido com **HTML, CSS e JavaScript** para praticar conceitos fundamentais do desenvolvimento web.

---

## Funcionalidades

- Tabuleiro 3x3 interativo
- Alternância entre jogadores X e O
- Detecção de vitória
- Detecção de empate
- Botão para reiniciar a partida
- Alternância de tema claro/escuro
- Link para o GitHub no rodapé

---

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
